# سطح بگا رفتگی

یک میکرو‌اپ فارسی برای تخمین وضعیت مالی در ایران بر اساس درآمد خانوار، اندازه خانوار، مسکن و سناریوی تورم.

> این پروژه فعلاً MVP و ابزار تحلیلی/سرگرمی است و طبقه‌بندی رسمی اقتصادی نیست.

## MVP
- رابط فارسی RTL با Vazirmatn
- درآمد ماهانه و تعداد اعضای خانوار
- اثر هزینه مسکن
- ۱۰ سطح «بگا رفتگی»
- معادل دلاری نمایشی
- شبیه‌سازی افت قدرت خرید با تورم
- مثال گیمینگ/روزمره برای قابل‌فهم شدن نتیجه

## مرحله بعد
- اتصال نرخ دلار و طلا به منبع زنده
- کالیبراسیون سطوح با داده‌های World Bank/PIP و داده‌های هزینه و درآمد خانوار ایران
- استفاده از مقیاس تعدیل‌شده خانوار OECD
- مدل PPP و مقایسه قدرت خرید جهانی
- سناریوهای رشد حقوق در کنار تورم
- ذخیره‌سازی تاریخچه و نمودار
